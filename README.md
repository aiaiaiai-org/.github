# aiaiaiai organization metadata

This repository contains the shared GitHub organization metadata for [`aiaiaiai-org`](https://github.com/aiaiaiai-org).

## Organization profile

The public organization profile is defined in [`profile/README.md`](profile/README.md) and rendered on the organization overview page.

Canonical public identity: [aiaiaiai.org](https://aiaiaiai.org).

## Scope

This repository is reserved for organization-wide GitHub configuration and metadata, including:

- the public organization profile;
- shared issue and pull request templates;
- organization-wide contribution guidance;
- reusable community health files;
- other GitHub-specific defaults shared across repositories.

Project code and product documentation belong in their respective repositories.
