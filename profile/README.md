## Principles

- Contracts over assumptions.
- Provider-agnostic cores.
- Human- and machine-readable state.
- Verified behavior over claims.
- Local-first computation where it materially improves ownership, privacy, or latency.

The canonical public identity is **aiaiaiai**. Organization context is versioned in [`mind`](https://github.com/aiaiaiai-org/mind); visual identity assets are maintained separately from product implementation.
